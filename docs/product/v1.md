# v1 scope

v1 is a **local execution shadow**: emit, store, project, inspect, time-travel visualize. Implementation follows [development-guide.md](../development/development-guide.md). This document is the product boundary.

## v1 includes

- Universal Agent Event Protocol
- Python SDK
- Event IDs, run IDs, per-run sequence numbers
- `contextvars` execution context
- Decorators / context managers
- Async event batching
- Local collector
- JSONL event storage
- Deduplication
- Out-of-order handling
- ProjectionEngine
- Graph projection
- Timeline projection
- Run / node state
- REST API
- WebSocket state patches
- React execution graph
- Timeline
- Node inspector
- Basic “Why?” structured metadata display
- Visualization replay

## v1 does not include

- Database
- Distributed collector
- Cloud deployment
- Authentication
- Multi-tenancy
- Arbitrary process checkpointing
- Generic agent re-execution
- Sophisticated optimization
- Automatic agent modification
- Hidden chain-of-thought capture
- Production-grade runtime control
- Full experience graph

## Acceptance (Week 3)

A sample agent with sequential nodes, fan-out, retry, and a loop must show live graph, timeline, node states, repeated execution, parallel branches, retry, and loop iterations.

Refresh/reconnect restores state from JSONL.

Replaying the stream through ProjectionEngine yields the same state as live incremental apply.
